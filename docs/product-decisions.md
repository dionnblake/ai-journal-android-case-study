# Product Decisions

## Target user

Busy founder/operator who wants a structured way to capture daily reflection, review patterns, and turn raw thoughts into sharper insight.

## Product problem

Normal journals capture thoughts but do not help users analyze them, spot patterns, or connect reflection to execution. This app aims to make journaling feel operational instead of passive.

## Key product choices

### Local-first entries

Journaling data is sensitive. The product favors on-device storage rather than treating entries as generic cloud content.

### AI as assistant, not replacement

AI features are designed to support reflection and summarization. The user remains the source of truth.

### Executive visual identity

Dark UI, high contrast, and gold accenting were used to make the app feel serious, private, and focused rather than playful or generic.

### Multiple input modes

Typing is not always the easiest path for daily reflection, so voice note support gives users a faster capture route.

### Export support

PDF and CSV export make the data portable and useful outside the app.

## Showcase decision

The public repository is a case study, not an open-source release. This protects the core implementation while still proving product, architecture, and execution ability.
